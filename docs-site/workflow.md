# Development workflow

Codexis is still in its feasibility phase. Work from the repository root and keep commits small so each experiment can be reviewed independently.

## Change Rust bridge APIs

Install the pinned code generator once, then regenerate bindings after changing the Rust API:

```bash
cargo install flutter_rust_bridge_codegen --version 2.13.0 --locked
cd <repo-root>
flutter_rust_bridge_codegen generate --config-file flutter_rust_bridge.yaml
```

Generated files live under `app/lib/src/rust/` and `engine/crates/codexis-core/src/frb_generated.rs`. Do not hand-edit generated bindings.

## Run local checks

```bash
# Rust
cd engine
cargo fmt --all --check
cargo test -p codexis-core

# Flutter
cd ../app
flutter analyze
flutter test
```

The direct bridge test loads the Linux host library generated by Flutter's Native Assets hook. The device-side test source is in `app/integration_test/`; run it with a connected supported Android ARM64 device using `flutter test integration_test/rust_bridge_test.dart -d <device-id>`.

## Review an Android build

```bash
cd app
flutter build apk --debug --target-platform android-arm64 --no-pub
```

An APK build proves compilation and packaging. It does not prove process execution, server lifecycle behavior, LSP framing, or semantic navigation on Android. Record those as separate experiments in `docs/PHASE_0.md`.

## Build this documentation site

```bash
cd docs-site
npm ci
npm run dev
npm run build
npm run preview
```

The site follows the app's implementation, not the architecture's intended future modules. Update [status](/status) whenever a measured result changes, and label plans as plans.

## Engineering constraints

- Keep file access and analysis local; do not add a cloud indexing path.
- Preserve the read-only product mode.
- Do not execute workspace build scripts in the default untrusted mode.
- Keep Tree-sitter structure parsing separate from LSP semantic results.
- Never report a server as supported from an initialize response alone; validate definitions and references in a real workspace.
